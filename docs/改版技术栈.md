# PetraDev · 改版技术栈与实现说明

> 本文只描述**我们自己的改版**（下称 PetraDev），不包含上游原版的功能说明。
> 上游基线：`f9662f4 baseline: Petra 0.3.3 original source before trimming`
> 当前产物：`src-tauri/target/release/PetraDev.exe`（75 MB，已签名）
> 文档更新：2026-11-02

---

## 一、改版定位

PetraDev 是在开源项目 Petra（Live2D 桌面宠物，Tauri 2）基础上做的**精简 + 交互改造**版本，目标不是新增功能，而是：

1. **砍掉不需要的模块**（语音、小游戏、抽卡、反馈、官网入口），把体积和依赖降下来；
2. **重做桌宠与窗口的交互模型**（缩放、拖拽、待机、自由出屏），使其在 2048×1152 / 200% 缩放的屏幕上真正好用；
3. **修正模型渲染缺陷**（首帧缺头、视线不跟随参数被覆盖）；
4. **与上游产物彻底区分**（改名 PetraDev、独立签名、独立快捷方式），避免混淆。

改版共 16 个提交（1 个上游基线 + 15 个改版提交），相对上游基线：**109 个文件变更，新增 291 行，删除 25,213 行**。

## 三、改版做了什么

### 3.1 功能删减（-25,213 行）

| 模块 | 删除内容 | 规模 |

| **小游戏** | `src/games/`、右键「小游戏」、`public/mahjong/` 整套素材（音频 / 牌面 SVG / 主题图）、立直脚本 | 91 个删除文件中的大多数 |
| **抽卡** | `src/features/card/`、`daily_card` 工具、菜单入口 | 目录整体删除 |
| **反馈** | 反馈面板、Rust `send_feedback` / `export_feedback` / `feedback_text`（飞书 / SMTP 双通道） | 后端 -1,177 行 |
| **官网入口** | 右键菜单外链 | — |

三个 trim 提交的删除量：前端 `96f648e` **-18,035 行**、`8daa618` **-5,752 行**、后端 `6e74291` **-1,177 行**。删除文件 91 个，其中 `public/mahjong/` 整套素材占绝大部分体积（约 6.4 MB）。

### 3.2 交互与显示改造（10 个提交）

| 提交 | 改动 | 作用 |
|---|---|---|
| `23f3e3d` | 大小滑块驱动显示尺寸；待机缩至 1/4 贴右下角；首帧预热 | 解决"启动时头消失"、缩放不生效 |
| `f7fb421` | 待机时模型推到窗口右下角 | 待机不再居中悬空 |
| `f955a6f` | 窗口跟随模型尺寸；待机固定 40%；离开待机拉回工作区 | 200% 时窗口不被裁切 |
| `a0cafbe` | 大小面板钉在窗口顶部；窗口尺寸夹紧工作区 | 拖动时面板不再跳动 |
| `efde66c` | 面板固定宽度、可拖动、与模型解绑；恢复真实 200% | 面板不再跟着模型跑 |
| `0a29770` | 自由拖拽（模型可出屏）；「重启记住大小与位置」开关；更窄面板 | 用户可把模型拖出屏幕 |
| `c3f5f28` | 竖版 150px 面板；中心锚定缩放；允许左/右/下出屏 | 顶部仍限制，避免拖没 |
| `639f10d` | 拖动中窗口位置不动，松手才重定位 | 消除面板抖动 |

配套的渲染修复（未单独成提交，落在上述提交内）：

- **视线跟随**：把 Cubism 参数写入包装进 `coreModel.update()` 之前（`Live2DController.ts`），否则模型内置动作会覆盖参数；
- **首帧预热**：模型加载后先 `model.update(0)` 再延迟显示，避免大纹理（6666×6666）首帧只画身体不画头；
- **缩放解耦**：位置用 `window.innerWidth/Height`，大小用 `displayW`，拖动滑块时即使窗口尚未 resize，模型也不会画出边界。

### 3.3 标识与命名（与上游区分）

| 项 | 上游 | PetraDev |
|---|---|---|
| 产物文件名 | `petra.exe` | **`PetraDev.exe`** |
| 进程名 | `petra` | **`PetraDev`** |
| `productName` | Petra | **PetraDev** |
| 窗口标题 | 绯羽 | **绯羽 · 改版** |
| 托盘 tooltip | Petra | **Petra 改版** |
| 桌面快捷方式 | Petra | **Petra 改版.lnk** |
| **identifier** | `com.wumiu.petra` | **保持不变**（关键约束） |

`identifier` 必须保持 `com.wumiu.petra`：它决定了 WebView2 用户数据目录（`%LOCALAPPDATA%\com.wumiu.petra\EBWebView`）与应用数据目录，改动会导致配置、日志、模型全部重置，且历史上出现过"改了就窗口消失"的问题。

改名实现方式（不侵入业务代码）：

- `Cargo.toml` 增加 `[[bin]] name = "PetraDev" path = "src/main.rs"`，crate 名 `petra_lib` 不变；
- `tauri.conf.json` 改 `productName` 与窗口 `title`；
- `lib.rs` 托盘 `.tooltip("Petra 改版")`。

```powershell
$env:RUSTUP_HOME = "C:\dsh  GZQ\build_tools\rustup"

# 2) 构建（前端 tsc + vite → dist；cargo release → 嵌入 dist）
cd "C:\dsh  GZQ\build\petra-src\Petra-master"
.\node_modules\.bin\tauri.cmd build --no-bundle

# 3) 签名（管理员）
C:\dsh  GZQ\build\resign-petra.ps1

# 产物
# src-tauri\target\release\PetraDev.exe
```

### 4.3 产物构成

| 项 | 值 |
|---|---|
| 大小 | 78,646,272 字节（75 MB） |
| 内容 | Rust 代码 + 前端 `dist`（JS/CSS）+ Live2D 模型（`model3.json` 及其纹理） |
| 嵌入方式 | `tauri::generate_context!()` 在编译期把 `frontendDist`（`../dist`）打进去 |

> 注意：**裸 `cargo build --release` 得到的 exe 不含前端资源**（约 13 MB），运行时会去连 `http://127.0.0.1:1420`（devUrl），表现为"127.0.0.1 拒绝连接"。必须用 `tauri build`。

### 4.4 代码签名

| 项 | 值 |
|---|---|
| 证书主体 | `CN=Wumiu Petra Dev` |
| 类型 | 自签名代码签名证书（SHA256） |
| 有效期 | 10 年（至 2036-10-20） |
| 安装位置 | `LocalMachine\My` + `LocalMachine\Root` + `LocalMachine\TrustedPublisher` |
| 签名工具 | `Set-AuthenticodeSignature` |
| 重签脚本 | `C:\dsh  GZQ\build\resign-petra.ps1` |

**每次重新构建 exe 后必须重签**，否则签名丢失。

签名效果与边界：

- ✅ UAC 提示显示"已验证的发布者 `Wumiu Petra Dev`"，不再是"未知发布者"；
- ❌ SmartScreen 仍可能拦截（Microsoft 信誉库不认自签名证书），需要用户点"仍要运行"，或在安全中心关闭"检查应用和文件"；
- ❌ 自签名无法消除 UAC 本身（提权确认是 Windows 机制）。

## 五、运行要求与已知限制

### 5.1 运行要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10/11 x64 |
| 运行时 | Edge WebView2 Runtime（Win10 通常已装，Win11 内置） |
| 权限 | **需要以管理员身份运行**（实测非提权下 WebView2 初始化失败，`petra.exe`/`PetraDev.exe` 报 `os error 5` 后窗口空白） |
| 启动方式 | 手动双击/右键"以管理员身份运行"、或桌面快捷方式 |

### 5.2 已知限制（踩过的坑）

| 现象 | 原因 | 结论 |
|---|---|---|
| 启动后无窗口、日志 0 字节 | 进程被放进 Job 对象，WebView2 子进程在 `msedge_elf.dll` 处 `0x80000003` 崩溃 | 计划任务 / WMI / shell 子进程启动都会触发；**只能由 explorer 直接启动** |
| 双击弹 SmartScreen + UAC 两个窗 | 自签名无信誉 + 管理员提权 | 签名解决前者，后者无法免除 |
| 与上游 Petra 不能同时运行 | 共用 identifier，单实例锁是同一把 | 要共存必须改 identifier（会重置数据，不推荐） |
| 非提权运行写日志失败 | 沙箱/权限不足，`OpenOptions` 返回 `os error 5` | 提权运行可解 |
| dev 构建提示"127.0.0.1 拒绝连接" | 裸 `cargo build` 或 debug 构建连 devUrl | 用 `tauri build` 产物 |

### 5.3 资源占用（实测）

| 指标 | 值 |
|---|---|
| 主进程 RSS（启动后） | 约 31 MB |
| WebView2 子进程 | 额外 2–4 个进程，合计约 100 MB |
| 渲染帧率 | 上限 30 fps（`ticker.maxFPS = 30`） |
| 后台线程 | 穿透采样 16 ms、拖拽跟随 8 ms、媒体轮询 500 ms、音频回环采集 |
